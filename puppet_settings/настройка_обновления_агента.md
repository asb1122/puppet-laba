Чтобы изменить периодичность обновлений Puppet-агента на node2-01, нужно настроить параметр runinterval в конфигурационном файле агента. По умолчанию агент запускается каждые 30 минут .

📝 Как это сделать
Выполните следующие шаги на сервере node2-01:

1. Измените параметр runinterval

Вы можете сделать это командой puppet config set, которая автоматически запишет настройку в нужный раздел файла /etc/puppetlabs/puppet/puppet.conf .

Например, чтобы агент запускался каждый час, выполните:
````
bash
sudo /opt/puppetlabs/bin/puppet config set runinterval 1h --section agent
````
Вы можете указать любое удобное значение, используя суффиксы:

30m — 30 минут (значение по умолчанию)

15m — 15 минут

2h — 2 часа

900 — 900 секунд (эквивалентно 15 минутам) 

2. Перезапустите службу агента

Чтобы изменения вступили в силу, необходимо перезапустить службу Puppet-агента :
````
bash
sudo systemctl restart puppet
````
✅ Проверка результата
После перезапуска можно убедиться, что настройка применилась:
````
bash
sudo /opt/puppetlabs/bin/puppet config print runinterval
````
Команда должна вывести заданное вами значение (например, 1h).
